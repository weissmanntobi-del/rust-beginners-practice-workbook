# Rust-Beginners-Practice-Workbook  <br/>
Rust Beginners Practice Workbook (40 Problems + 1 Mini Project) <br/>
Build real confidence with Rust by solving, not just reading. <br/>

If you already know basic Rust syntax but still get stuck when writing code from scratch, this workbook is for you. It gives you a structured path of beginner-friendly exercises that gradually level you up—so <br/> 
you’re ready to move into an advanced Rust course (ownership/deep lifetimes/advanced traits/async) with much less pain. <br/>

## What you’ll get <br/>
✅ 40 carefully curated beginner problems (progressive difficulty) <br/>
✅ 1 Mini Project to combine everything into a real program <br/>
✅ Exercises focused on “Rust thinking”: correctness, safety, and clean code <br/>
✅ Clear instructions + expected outputs + hints (without giving away everything) <br/>

## What you’ll practice (skills you must have before Rust Advanced) <br/>
1) Variables, mutability, shadowing <br/>
2) Integers/floats/bool/char + type inference <br/>
3) Strings: String vs &str <br/>
4) Arrays, tuples, destructuring <br/>
5) if/else, loops, and match foundations <br/>
6) Functions, return values, expressions vs statements <br/>
7) Basic error handling patterns with Option / Result (intro level) <br/>
8) Structs/enums (intro level) and simple modules <br/>
9) Writing small, testable programs <br/>

## Mini Project <br/>
1) A structured mini project at the end helps you practice: <br/>
2) input → processing → output <br/>
3) structuring code into functions/modules <br/>
4) clean CLI-style workflow <br/>
5) basic validation + error paths <br/>

## Who this is for : <br/>
1) Beginners who finished a Rust intro but still don’t feel “ready” <br/>
2) People working through Rustlings or Rust books and want extra practice <br/>
3) Developers from Java/Python/JS who want Rust muscle-memory <br/>
4) What you should know before starting <br/>
5) How to install Rust and run cargo run <br/>
6) Basic familiarity with variables and functions (even from another language) <br/>
